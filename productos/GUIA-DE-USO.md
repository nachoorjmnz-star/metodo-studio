# Guía de uso — Productos Método

Cómo convertir cada archivo de esta carpeta en el producto que reciben tus clientes.

> **Idea clave:** los `.csv` son la *versión de arranque*. Para venderlos, súbelos a **Google Sheets**, añade las fórmulas del panel (suma por categoría, % y gráficos) y comparte el enlace **"Hacer una copia"**. Así el cliente se lleva su propia copia editable.

---

## 📊 Plantillas de hoja de cálculo (.csv)
`control-total` · `libertad-freelance` · `reto-52-semanas` · `habitos` · `calendario-contenido` · `cliente-crm`

1. Ve a Google Sheets → **Archivo → Importar → Subir** el `.csv`.
2. Da formato: cabeceras en negrita, colores de Método (verde `#2E5A4C`), congela la fila 1.
3. Añade el **panel**: una pestaña "Resumen" con `SUMAR.SI` por categoría, `%` gastado y un gráfico.
4. **Archivo → Compartir → Publicar**, o mejor: copia el enlace y cámbiale el final por `/copy`
   (ej: `.../edit` → `.../copy`). Ese es el enlace que entregas.
5. Exporta también una versión **Excel** (`.xlsx`) para quien no use Google.

## 🧠 Segundo Cerebro (.md → Notion)
1. Abre Notion → nueva página → pega el contenido de `segundo-cerebro.md`.
2. Convierte los bloques **[Base de datos]** en tablas (`/tabla`).
3. Menú `•••` de la página → **Plantillas** → genera el enlace de **"Duplicar"** público.
4. Ese enlace de duplicar es el producto.

## 📅 Planner 2026 (.html → PDF)
1. Abre `planner-2026.html` en Chrome.
2. Botón **"Guardar como PDF / Imprimir"** (arriba a la derecha) → Destino: *Guardar como PDF* → tamaño A4.
3. El PDF resultante es el producto (funciona en GoodNotes, Notability, iPad o impreso).
